- **음성 재생 함수 0x06003BE4(r4 = 번호)**: 번호 → «PCM%04d.AIF» → GFS 열기 → 사운드 램 0x25A78000(0xA000 고리)로 스트림. 상태 0x0604D480(재생 중 1), 번호 변수는 시작 때 지워짐 → 훅이 직접 기록해야.
  부르는 곳 2: 0x0602BB76(필드, 번호 = 0x0604D478 u32, 리터럴 0x0602BC24) · 0x06021724(번호 = 0x06063CC0 u8, 리터럴 0x060217B0) → 리터럴 두 곳만 감싸개로 돌리면 됨(명령 이동 없음).
  0x06003734 = 같은 번호로 먼저 부르는 디렉터리 바꾸기.
- **VBlank**: BIOS 표 0x06000A00 → 공통 분배기 0x0603582C → 표 0x0607BF6C+번호×4. VBlank-IN 0x060020E4(리터럴 0x06002314) · VBlank-OUT 0x060020F8(리터럴 0x06002318).
- **화면**: 음성 장면 = NBG2(대사 창 층) 우선순위 0(꺼짐), 포트레이트 = VDP1. VDP1 명령 13개(END 0x1A0), 필드 75개(END 0xD0E0). VDP1 VRAM 0x76800~0x78000(6 KB) 스테이트 15개 모두 0 → 자막 그림 자리.
